# 数据源评价标准详细说明

本文档详细说明 bearing-data-source-filter Skill 中使用的各项评价指标及其计算逻辑。

## 一、评价指标体系总览

```
综合得分 = 响应效率得分 × 0.30 + 数据质量得分 × 0.40 + 网站质量得分 × 0.30
```

## 二、响应效率指标（权重30%）

### 2.1 响应时间得分（权重40%）

| 响应时间 | 得分 | 说明 |
|---------|------|------|
| < 1000ms | 100 | 极快 |
| 1000-2000ms | 90 | 很快 |
| 2000-3000ms | 80 | 快 |
| 3000-5000ms | 60 | 一般 |
| 5000-8000ms | 40 | 较慢 |
| 8000-10000ms | 20 | 慢 |
| > 10000ms | 0 | 极慢 |

计算公式：`score = max(0, 100 - avg_response_time_ms / 100)`

### 2.2 访问成功率得分（权重40%）

| 成功率 | 得分 | 说明 |
|-------|------|------|
| 100% | 100 | 完全稳定 |
| 75%-99% | 成功率×100 | 偶有失败 |
| 50%-74% | 成功率×80 | 不稳定 |
| < 50% | 0 | 极不稳定 |

计算公式：`score = success_rate × 100`

### 2.3 稳定性得分（权重20%）

基于多次访问中响应时间是否异常（>5000ms视为异常）计算：

计算公式：`score = 1.0 - (异常次数 / 总次数)`

### 响应效率得分汇总

```
响应效率得分 = 响应时间得分 × 0.4 + 访问成功率得分 × 0.4 + 稳定性得分 × 100 × 0.2
```

## 三、数据质量指标（权重40%）

### 3.1 企业信息丰富度（权重35%）

检测页面中是否包含以下企业相关信息关键词：
- 企业标识：企业名称、公司名称、厂商名称、厂家名称
- 联系信息：地址、电话、传真、邮箱、联系人
- 经营信息：主营、产品、业务、经营范围
- 规模信息：注册资本、成立时间、员工、规模
- 企业概况：简介、介绍、概况、关于
- 其他信息：官网、法人代表、认证、资质

评分逻辑：
- 匹配10个及以上关键词：满分1.0
- 每少一个关键词扣0.1分
- 页面包含列表/表格结构：额外+0.15分
- 最高不超过1.0

### 3.2 行业相关性（权重35%）

检测页面内容是否与轴承行业相关：

**中文关键词**（每个匹配+0.125分）：
- 企业/公司/厂家/厂商/制造商/供应商
- 轴承/滚动轴承/深沟球/圆锥滚子/调心滚子/圆柱滚子
- 滑动轴承/关节轴承/直线轴承/推力轴承
- 保持架/滚动体/密封圈/润滑
- 轴承钢/GCr15/陶瓷轴承/不锈钢轴承
- 内径/外径/精度等级/额定载荷/极限转速
- 热处理/磨削/超精加工/锻造/车削
- AS9100/API/CRCC/IRIS
- 专利/商标/知识产权
- 注册/工商/资本/法人/股东
- 招标/中标/采购/投标
- 产品/型号/规格/参数
- 名录/黄页/数据库

**英文关键词**（每个匹配+0.05分）：
bearing, ball bearing, roller bearing, thrust bearing, linear bearing, linear guide, ball screw, tapered roller, deep groove, angular contact, spherical, cylindrical roller, bearing steel, ceramic bearing, enterprise, manufacturer, supplier, directory

评分逻辑：`score = min(1.0, matched_count / 8.0)`

### 3.3 数据结构化程度（权重20%）

检测页面是否使用结构化方式展示数据：

| 结构化特征 | 加分 | 说明 |
|-----------|------|------|
| 表格(table) | 0.05/个，最高0.3 | 表格通常表示结构化数据 |
| 列表(ul/ol) | 0.03/个，最高0.2 | 列表展示 |
| 定义列表(dl) | 0.05/个，最高0.2 | 键值对展示 |
| 卡片布局 | 0.02/个，最高0.3 | div卡片类布局 |

评分逻辑：各项加分累计，最高1.0

### 3.4 数据时效性（权重10%）

检测页面内容是否包含近期信息：

| 时间特征 | 得分 | 说明 |
|---------|------|------|
| 包含当年或去年年份 | 1.0 | 数据很新 |
| 包含前年年份 | 0.7 | 数据较新 |
| 包含3年前年份 | 0.4 | 数据较旧 |
| 无明确时间标记 | 0.3 | 无法判断 |

### 数据质量得分汇总

```
数据质量得分 = 企业信息丰富度×100×0.35 + 行业相关性×100×0.35 + 数据结构化×100×0.20 + 数据时效性×100×0.10
```

## 四、网站质量指标（权重30%）

### 4.1 页面质量（权重40%）

基础分0.5，根据以下因素调整：

| 因素 | 调整 | 说明 |
|------|------|------|
| 页面HTML长度>50000 | +0.2 | 内容丰富的页面 |
| 页面HTML长度>20000 | +0.1 | 内容较丰富的页面 |
| 纯文本内容>3000字 | +0.2 | 有大量可读文本 |
| 纯文本内容>1000字 | +0.1 | 有一定可读文本 |
| 页面包含404/错误提示 | -0.3 | 页面无法正常显示 |

### 4.2 反爬友好度（权重30%）

基础分0.5，根据以下因素调整：

| 因素 | 调整 | 说明 |
|------|------|------|
| 页面包含验证码 | -0.4 | 反爬严格 |
| 页面包含访问限制提示 | -0.3 | 有访问频率限制 |
| 响应时间>8秒 | -0.2 | 响应极慢 |
| 响应时间>5秒 | -0.1 | 响应较慢 |
| 页面有丰富内容 | +0.2 | 说明返回了正常页面 |

### 4.3 内容可信度（权重30%）

基础分0.3，根据以下因素调整：

| 因素 | 调整 | 说明 |
|------|------|------|
| 政府域名(.gov.cn等) | +0.4 | 官方权威来源 |
| 知名平台域名 | +0.2 | 行业知名平台 |
| 页面包含"官方"/"政府"/"协会"等词 | +0.1 | 权威来源标识 |

### 网站质量得分汇总

```
网站质量得分 = 页面质量×100×0.4 + 反爬友好度×100×0.3 + 内容可信度×100×0.3
```

## 五、分类推断规则

当网站分类未知时，根据以下规则自动推断：

| 分类 | 判断规则 |
|------|---------|
| 工商查询 | 域名包含tianyancha/qcc/qixin/aiqicha/gsxt |
| 招投标平台 | 域名包含bid/zhaobiao/tender/ccgp/ggzy/chinabidding |
| 专利平台 | 域名包含patent/cnipa/zhuanli/soopat/trademark |
| B2B平台 | 域名包含1688/alibaba/zcw168/zcjob88/b2b，或内容包含供应/采购/求购/批发 |
| 行业媒体 | 域名包含news/media/cbia/mw1950/zcgy/mei/industry，或内容以资讯为主 |
| 企业名录 | 内容包含大量"名录"/"黄页"/"directory"/"企业列表" |
| 综合平台 | 不符合以上任何规则 |

## 六、评价等级划分

| 综合得分 | 等级 | 说明 |
|---------|------|------|
| >= 85 | A级(优秀) | 强烈推荐使用 |
| 70-84 | B级(良好) | 推荐使用 |
| 55-69 | C级(一般) | 可用，但需注意局限性 |
| 40-54 | D级(较差) | 谨慎使用 |
| < 40 | E级(差) | 不推荐 |

## 七、使用建议

1. **优先使用A/B级网站**：这些网站响应快、数据质量好、采集难度低
2. **C级网站作为补充**：当A/B级网站数据不足时，可作为补充来源
3. **D/E级网站慎用**：仅在特殊需求时考虑，需人工验证
4. **定期重新评价**：网站质量会随时间变化，建议定期重新运行评价
5. **关注分类均衡**：尽量选择不同分类的网站，确保数据覆盖面
