# 轴承行业企业标签体系

## 标签体系总览

```
标签体系
├── 产品标签
│   ├── 核心产品类型
│   ├── 产品规格标签
│   ├── 产品应用场景
│   └── 产品合规标签
├── 服务标签
│   ├── 核心服务类型
│   ├── 合作模式标签
│   ├── 服务覆盖范围
│   └── 增值服务标签
└── 能力标签
    ├── 技术能力标签
    ├── 生产能力标签
    ├── 资质能力标签
    └── 资金实力标签
```

## 四、标签扩展规则

1. **细分领域扩展**：针对滚动轴承/滑动轴承/关节轴承/直线运动/零部件等细分领域新增专属标签
2. **字段联动扩展**：模块2新增字段可同步新增对应标签
3. **行业适配扩展**：结合行业发展趋势新增新兴标签（如风电主轴轴承、高铁轴承、新能源汽车轴承等）

## 五、标签标准化规则

1. **术语统一**：DGBB→深沟球轴承、HRB→调心滚子轴承、TRB→圆锥滚子轴承
2. **格式统一**：标签表述简洁规范，去除冗余
3. **歧义消除**：模糊字段生成标签标注"未明确"
4. **层级统一**：一级标签-二级标签，不新增三级标签
