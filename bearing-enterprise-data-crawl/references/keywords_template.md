## 搜索引擎语法

### 百度搜索语法
```
site:gov.cn {企业名称}          # 仅政府网站
site:ccgp.gov.cn {企业名称}      # 政府采购网
{企业名称} -推广 -广告           # 排除广告
{企业名称} filetype:pdf          # PDF文档
```

### 搜狗搜索语法
```
{企业名称} 官网                 # 官网认证
{企业名称} -VIP -会员           # 排除付费
```
