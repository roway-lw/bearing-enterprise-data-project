# 目标采集渠道清单

## 一、企业官方网站
- 优先采集板块：「关于我们」「产品中心」「新闻动态」「投资者关系」
- 采集策略：官网域名通常与企业名称直接相关，使用百度/Google 搜索 `企业名称 官网`

## 二、政府公开平台

### 国家层面
| 平台名称 | 网址 | 采集内容 |
|---------|------|---------|
| 国家企业信用信息公示系统 | http://www.gsxt.gov.cn | 工商登记信息、经营异常、行政处罚 |
| 国家发展和改革委员会 | https://www.ndrc.gov.cn | 项目审批、备案公示 |
| 工业和信息化部 | https://www.miit.gov.cn | 企业公告、行业准入 |
| 生态环境部 | https://www.mee.gov.cn | 环评公示、环境处罚 |
| 国家知识产权局 | https://www.cnipa.gov.cn | 专利申请、商标注册 |
| 国家版权局 | https://www.ncac.gov.cn | 软件著作权、作品登记 |

### 地方层面
| 平台名称 | 采集内容 |
|---------|---------|
| XX省/市发展和改革委员会 | 投资项目备案、审批 |
| XX省/市工业和信息化局 | 企业技术改造公告 |
| XX省/市市场监督管理局 | 工商年报、行政处罚 |
| XX省/市生态环境局 | 环评受理、审批公示 |
| XX省/市公共资源交易中心 | 土地/工程招标 |

## 五、行业新闻平台

### 权威媒体
- 新华网、人民网、央视网
- 中国新闻网
- 各行业协会官网

### 产业媒体
- 根据企业所属行业选择对应的产业媒体

## 六、企业公开年报

- 巨潮资讯网 (cninfo.com.cn) - A股上市公司年报
- 上交所/深交所官网 - 上市企业公告
- 全国中小企业股份转让系统 - 新三板企业公告

---

## 采集优先级

1. **高优先级**：官网、工商业公示、招标公告、专利信息
2. **中优先级**：环评公示、行业新闻
3. **低优先级**：社交媒体提及、行业分析报告
