# 字段提取正则模板

## 企业基础信息

### 企业名称
```
([\u4e00-\u9fa5]+(?:轴承|精密|机械|传动|冶金|装备|机电|五金|钢铁|科技|技术|制造|工业)+有限公司)
```

### 成立时间
```
(\d{4})\s*年\s*(\d{1,2})\s*月\s*(\d{1,2})\s*日
(\d{4})\s*[-/]\s*(\d{1,2})\s*[-/]\s*(\d{1,2})
成立于?\s*(\d{4})\s*年\s*(\d{1,2})\s*月\s*(\d{1,2})\s*日
```

### 注册地址
```
(?:注册地址|地址|住所|经营地址|位于)\s*[:：]?\s*([\u4e00-\u9fa5\d\-省市县区路街道号室栋楼层]+)
```
省级开头：
```
((?:北京|上海|天津|重庆|广东|浙江|江苏|山东|福建|四川|陕西|湖北|湖南|安徽|河北|河南|辽宁|江西|广西|云南|贵州|甘肃|海南|宁夏|青海|新疆|西藏|内蒙古)[\u4e00-\u9fa5\d\-省市县区路街道号室栋楼层]+)
```

### 法定代表人
```
法定代表人\s*[:：]?\s*([\u4e00-\u9fa5]{2,4})
法人代表\s*[:：]?\s*([\u4e00-\u9fa5]{2,4})
法人\s*[:：]?\s*([\u4e00-\u9fa5]{2,4})
```

### 注册资本
```
注册资本\s*[:：]?\s*([\d.]+)\s*万(元|人民币)
注册资本\s*[:：]?\s*([\d.]+)\s*亿元
注册资本\s*[:：]?\s*([\d.]+)\s*亿
```

## 经营信息（轴承专属）

### 经营范围
```
经营范围\s*[:：]?\s*([\u4e00-\u9fa5，、；;,\s]+?)(?:。|$)
主营\s*[:：]?\s*([\u4e00-\u9fa5，、；;,\s]+?)(?:。|$)
```

### 产品规格
```
内径\s*[:：]?\s*([\d.]+)\s*[-~至]\s*([\d.]+)\s*mm         # 轴承内径范围
外径\s*[:：]?\s*([\d.]+)\s*[-~至]\s*([\d.]+)\s*mm         # 轴承外径范围
精度等级\s*[:：]?\s*(P[0-6]|ABEC-[1-9])                  # 精度等级
额定载荷\s*[:：]?\s*([\d.]+)\s*kN                         # 额定载荷
极限转速\s*[:：]?\s*([\d.]+)\s*r/min                      # 极限转速
轴承型号\s*[:：]?\s*([0-9]{4,}[A-Z0-9]*)                  # 轴承型号
宽度\s*[:：]?\s*([\d.]+)\s*mm                              # 轴承宽度
```

### 用工规模
```
(\d+)\s*[-~至]\s*(\d+)\s*人
员工\s*[:：]?\s*(\d+)\s*人
现有.*?(\d+)\s*人
```

## 资质信息

### 高新技术企业
```
高新技术企业|高新企业|高新技
```

### 专精特新
```
专精特新|小巨人
```

### 专利数量
```
(?:拥有|持有|获批|授权)\s*(\d+)\s*项\s*(?:发明)?专利
(?:发明)?专利\s*(\d+)\s*项
(\d+)\s*项\s*(?:发明)?专利
(?:实用新型|外观设计)\s*(\d+)\s*项
```

## 项目与招投标

### 招投标
```
(\d{4})\s*年.*?中标.*?(?:轴承|滚子|保持架|密封|润滑|热处理|磨削|装备).*?项目
中标.*?(?:轴承|滚子|保持架|密封).*?项目.*?([\d.]+)\s*万?元
```

### 投资项目
```
(\d{4})\s*年.*?(?:新增|建设|投资).*?(?:轴承|滚子|保持架|产线|生产线).*?项目
(?:新增|投资).*?(?:轴承|生产线).*?项目.*?([\d.]+)\s*亿?万?元
```

### 金额
```
([\d.]+)\s*亿元
([\d.]+)\s*万元
投资\s*([\d.]+)\s*亿
总投资\s*([\d.]+)\s*亿
```
